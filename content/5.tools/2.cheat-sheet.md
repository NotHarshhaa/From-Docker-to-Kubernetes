## Pro-Tips for Daily CLI Operations

### 1. Fast Namespace Switching
Instead of continuously passing `-n <namespace>` to every single `kubectl` command, set your context namespace permanently for the current shell session:

```bash
# Switch default namespace for all subsequent commands
kubectl config set-context --current --namespace=my-production-ns

# Verify current active namespace and context
kubectl config get-contexts
```

Or install `kubens` / `kubectx` from [ahmetb/kubectx](https://github.com/ahmetb/kubectx) for instant switching:
```bash
kubens my-production-ns
```

---

### 2. Streamlining Command Aliases
Boost your terminal productivity by configuring recommended aliases in your `~/.bashrc` or `~/.zshrc`:

```bash
# Essential Kubernetes Aliases
alias k="kubectl"
alias kgp="kubectl get pods -o wide"
alias kgs="kubectl get svc"
alias kgd="kubectl get deployments"
alias kl="kubectl logs -f --tail=100"
alias kx="kubectl exec -it"
alias kdp="kubectl describe pod"

# Essential Docker Aliases
alias d="docker"
alias dps="docker ps --format 'table {{.ID}}\t{{.Names}}\t{{.Status}}\t{{.Ports}}'"
alias dpa="docker ps -a"
alias dlog="docker logs -f --tail 100"
alias dcp="docker compose"
```

---

### 3. Safely Debugging Distroless & Scratch Containers
Production containers built without shells or diagnostic binaries can be inspected using Kubernetes Ephemeral Containers:

```bash
# Attach an interactive netshoot diagnostic container to a live pod
kubectl debug -it <pod-name> -n <namespace> \
  --image=nicolaka/netshoot \
  --target=<container-name>
```

This injects common networking and debugging tools (`curl`, `tcpdump`, `dig`, `iperf`, `strace`, `netstat`) into the target pod's network and process namespaces without modifying the production image itself.
